MyDrives

원격 저장소를 내 컴퓨터의 드라이브처럼 씁니다.

MyDrives는 Windows와 macOS에서 도는 오픈소스 데스크톱 앱입니다. NAS(SMB), FTP, 네이버 MYBOX, Google Drive, OneDrive, Dropbox를 탐색기와 Finder에 로컬 드라이브처럼 붙여 줍니다.

  • 파일은 내 컴퓨터와 저장소 사이에서만 오갑니다. 중개 서버가 없습니다.
  • 로그인 정보는 운영체제의 자격증명 저장소(키체인 / 자격 증명 관리자)에 둡니다.
  • 소스 전체가 공개되어 있습니다.
